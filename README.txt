Slaysi.si 3D Live Wallpaper — Windows Desktop App Package
======================================================

How to build your standalone .exe (1-click desktop wallpaper app):
1. Install .NET 8 SDK on your Windows PC (free from Microsoft).
2. Extract this ZIP folder and double-click `Build_App.bat`.
3. It will generate `dist\SlaysiWallpaper.exe` with your 3D HTML wallpaper embedded inside!
4. Run `SlaysiWallpaper.exe` — it automatically places itself behind your Windows desktop icons, tracks your mouse for 3D parallax, and adds a System Tray icon (Pause, Settings, Run at Startup, Exit).

Optional (Create Setup Installer for Customers):
- Install Inno Setup (free) and compile `Installer.iss` to generate `Slaysi-Wallpaper-Setup.exe` so users can install and launch it in 1 click.
